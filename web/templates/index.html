The drawing never rests on colour: a filled chip means we have positive evidence the capability works; a dashed border means no declaration was seen for it; a heavier border means something is actively wrong rather than merely missing; a dotted border means we did not look; and no border at all means nothing was there. The count beside each state is how many chips on this page are in it.

A chip on this page carries no words, so this is the one page where a state is drawn and not written out. Every row links to that endpoint's own page, where each verdict is named in words beside the metric it belongs to.

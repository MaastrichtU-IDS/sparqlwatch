The drawing never rests on colour: a filled chip means we have positive evidence the capability works; a dashed border means no declaration was seen for it; a heavier border means something is actively wrong rather than merely missing; a dotted border means we did not look; and no border at all means nothing was there. The count beside each state is how many chips on this page are in it.

A chip on this page carries no words, so this is the one page where a state is drawn and not written out. Every row links to that endpoint's own page, where each verdict is named in words beside the metric it belongs to.

{{ row_unfinished_text }} The sweep this row's facts came from recorded that it was being written one endpoint at a time and never recorded that it was complete. This endpoint's own chunk was written whole, which is how its facts got here, so what the row says is what that sweep had written for it when it stopped.

{{ row_never_reached_text }} A later sweep exists, stopped, and never recorded finishing this endpoint, so none of this row comes from it. Everything in the row is still the newest this service holds for the endpoint, and the sweep that recorded it may well have finished; what is not true is that this row reports the latest sweep.

{{ row_dormant_text }} The newest sweep published this endpoint as one it declined to ask. Where it gave a reason the row carries it, and where it gave none the row says that instead. The reasons a sweep can give, and the slugs are the prober's own rather than this template's: {% for reason in dormancy_reasons %}{{ reason.slug }}, {{ reason.gloss }}{% if not loop.last %}; {% endif %}{% endfor %}. How often the endpoint is asked next is part of the reason and not the marker, which is why each reason above carries its own and this panel states none. One of them is not a change in our rotation at all, and a row marked with that reason was not relegated and was not judged. Every one of them is a fact about this service and none is a verdict about the endpoint: dormancy is not a verdict, it has no chip and no entry in the key above, and the chips on the row are the ones its last real probe produced. A reason this build has no reading of is printed on the row exactly as the store holds it, and nothing is claimed about what it means. What the mark claims, what it does not, and how a person changes it are set out on this service's about page.
